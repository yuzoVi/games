# Godot Games

A growing collection of small games built with [Godot Engine 4.6](https://godotengine.org/).

> **AI-assisted projects.** All games in this series were developed with AI assistance as a way to learn game development and the Godot engine from the ground up.

---

## Games

| # | Game | Description | Repo |
|---|------|-------------|------|
| 01 | Snake | Classic snake game on a 20×20 grid | [snake-game](https://github.com/yuzoVi/snake-game) |
| 02 | Flappy Bird | Flappy Bird clone with pipe obstacles | [flappy-bird-clone](https://github.com/yuzoVi/flappy-bird-clone) |
